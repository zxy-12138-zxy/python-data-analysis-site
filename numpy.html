NumPy 简介

NumPy 是一个用于科学和工程计算的开源库，它提供了多维数组对象（ndarray）以及对这些数组进行高效操作的函数【111275191213374†L74-L78】【111275191213374†L115-L158】。由于其高速的矢量化运算、广播机制和内存效率，NumPy 成为 Python 数据分析和数值计算的核心库。

通常使用 import numpy as np 来导入该库【111275191213374†L81-L86】。

创建数组

NumPy 提供了多种创建数组的方法，例如从 Python 列表创建、使用内置函数生成特定序列等：

import numpy as np

# 从列表创建一维数组
arr1 = np.array([1, 2, 3])

# 创建二维数组
arr2 = np.array([[1, 2, 3],
                [4, 5, 6]])

# 使用内置函数创建序列
zeros = np.zeros((2, 3))     # 全零数组
ones = np.ones(4)            # 一维全一数组
arange = np.arange(0, 10, 2) # 0 到 8 的步长为 2 的数组

数组属性与索引

数组具有一些有用的属性，例如形状 (shape)、数据类型 (dtype) 等，可以用来了解数组的结构：

print(arr2.shape)  # 输出 (2, 3)
print(arr1.dtype) # 输出元素的数据类型

NumPy 使用 0 起始索引，可以通过切片访问子数组：

# 访问第二行第三列元素
element = arr2[1, 2]

# 访问第一行的前两列
subarray = arr2[0, :2]

向量化运算

NumPy 支持对整个数组进行元素级运算，而无需显式编写循环。例如：

x = np.array([1, 2, 3])
y = np.array([4, 5, 6])

# 元素级加法和乘法
sum_xy = x + y        # [5, 7, 9]
product_xy = x * y    # [4, 10, 18]

# 广播：不同形状的数组也可以运算
z = np.array([10])
result = x + z        # [11, 12, 13]

通过利用向量化运算，可以显著提高代码的执行效率。
