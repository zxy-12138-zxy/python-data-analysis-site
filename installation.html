环境准备与安装

Anaconda 是一个集成了众多科学计算和数据分析库的 Python 发行版，广泛应用于数据科学领域，并建议至少 4 GB 内存以流畅运行【897115196629532†L27-L33】。

安装步骤

  1. 访问 Anaconda 官网 并下载适用于您操作系统的 Python 3.x 版本安装包【897115196629532†L34-L39】。
  2. 按照安装程序指引完成安装。
  3. 安装完成后启动 Anaconda Navigator，这是一个图形化的管理界面。

启动 Jupyter Notebook

Anaconda 内置 Jupyter Notebook，可通过以下步骤启动【897115196629532†L53-L63】：

  1. 在 Anaconda Navigator 中点击 Launch 启动 Jupyter Notebook。
  2. 浏览器打开后，选择一个文件夹作为工作目录，然后点击 New → Python 3 创建新的 notebook。

包管理

在数据分析过程中常需安装或更新各种库。可以通过 conda 命令管理包【897115196629532†L116-L143】：

conda list            # 查看已安装的包列表
conda search pandas   # 搜索 pandas 包
conda install pandas  # 安装 pandas
conda remove pandas   # 卸载 pandas
