使用 Matplotlib 绘图

Matplotlib 是 Python 最常用的绘图库之一。一个图形由 Figure 对象和一个或多个 Axes 组成。可以通过 plt.subplots() 创建图和坐标轴，使用 ax.plot() 绘制数据，再调用 plt.show() 显示【769659793286892†L124-L134】。

import matplotlib.pyplot as plt

# 创建数据
x = [0, 1, 2, 3, 4]
y = [0, 1, 4, 9, 16]

# 创建图形和坐标轴
fig, ax = plt.subplots()
ax.plot(x, y, marker='o')
ax.set_xlabel('x')
ax.set_ylabel('y')
ax.set_title('简单折线图')

plt.show()

使用 Seaborn 绘图

Seaborn 是建立在 Matplotlib 之上的高级可视化库，提供了绘制统计图形的高级接口【321858038600472†L42-L45】。使用 Seaborn 可以更容易地绘制美观的信息图。

import seaborn as sns
import pandas as pd

# 创建示例数据
df = pd.DataFrame({
    '类别': ['A', 'B', 'C', 'D'],
    '值': [10, 23, 17, 5]
})

# 绘制条形图
sns.barplot(x='类别', y='值', data=df)
plt.title('类别对比条形图')
plt.show()

Seaborn 还支持散点图、箱线图、热力图等多种统计可视化，可以根据需要探索。
