变量与数据类型

在 Python 中，整数和浮点数分别被表示为 int 和 float 类型【230082119079088†L107-L109】。变量通过赋值语句创建，无需事先声明；下面演示了变量赋值及基本算术运算【230082119079088†L137-L145】：

# 数值类型
a = 10          # 整数 int
b = 3.14        # 浮点数 float

# 算术运算
sum_value = a + b      # 加法
product = a * b        # 乘法
power = a ** 2         # 幂运算（10 的平方）

Python 还提供字符串、列表、字典等复合类型，用于存储和处理复杂数据结构。

流程控制

条件语句

条件语句使用 if、elif 和 else 来根据条件执行代码块【658329677986108†L77-L101】：

score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"
print(grade)

循环

for 循环可以遍历序列中的每个元素【658329677986108†L109-L124】：

fruits = ["苹果", "香蕉", "橙子"]
for fruit in fruits:
    print(fruit)

使用 range() 可生成整数序列，用于循环计数【658329677986108†L147-L156】：

# 打印 0 到 4
for i in range(5):
    print(i)

函数

函数使用 def 关键字定义。函数体通过缩进表示，且可以包含文档字符串来说明功能【448517437935602†L550-L567】。参数传递采用对象引用，每次调用都会创建新的局部作用域【448517437935602†L579-L583】。使用 return 返回结果，若未指定返回值则默认返回 None【448517437935602†L631-L633】。

def greet(name):
    """根据传入的名字生成问候语"""
    message = f"你好，{name}!"
    return message

print(greet("小明"))

通过合理运用函数，可以将程序组织成可重用的模块，提高代码的可读性和维护性。
